# PALINODE controlled HTTPS fixture

This is fictional static test data. It does not represent a real company,
auditor, government, or institution.

The published `.well-known/palinode.json` body binds the resolved public
Studionet deployer/controller address to `https://palinode-fixture.vercel.app`
with nonce `PALINODE_FIXTURE_NONCE_V1` under the fixed
`WELL_KNOWN_ADDRESS_NONCE_V1` policy. The five-field body is the initial
authority declaration expected by the contract.

All artifact bodies are UTF-8 and deterministic. A release manifest records
the final canonical URLs, SHA-256 digests, and byte lengths after deployment.
